# Mouaz Brai — Personal Portfolio

Official portfolio website of **Mouaz Brai** — Full Stack Developer, Software Engineer, Automation Specialist, Graphic Designer, and Print Production Specialist.

🌐 **Live Website:** [https://mouazbrai.space](https://mouazbrai.space)

---

## Overview

A modular, responsive, and lightweight personal portfolio engineered with a clean white aesthetic and high-contrast `#ED1C24` brand identity. Designed to showcase both software engineering architectures and commercial graphic design & prepress works.

## Key Features

- **Modular Architecture:** Clean separation of concerns across global variables (`all-style.css`), section styles (`style.css`), responsive breakpoints (`responsive.css`), and dynamic DOM rendering (`main.js`).
- **Interactive Expertise Tabs (Jumbotron):** Categorized skillsets across Full Stack Development, Automation & Software, Graphic Design, and Print Production.
- **Qualifications & Academic Records:** Structured grid detailing the Senior Technician (BTS) in Printing Industries (Boudouaou), Professional Qualification Certificate (CFPA Baraki), Graduation Thesis (`MFE.pdf`), and language proficiencies.
- **Dual-Category Project Slider:** Interactive showcase for Web Development and Graphic Design & Print Production with slide-in hover overlays detailing project types, descriptions, and tech stacks.
- **SEO & Performance Optimized:** Configured with semantic HTML5, JSON-LD `ProfilePage` structured data, Open Graph metadata, canonical tags, `robots.txt`, and `sitemap.xml` for `mouazbrai.space`.
